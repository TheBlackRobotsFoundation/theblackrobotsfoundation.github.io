## Desarrollo

Este sitio está construido con [Docusaurus](https://docusaurus.io/).

### Instalación

```bash
npm install
```

### Servidor de desarrollo

```bash
npm start
```

### Build

```bash
npm run build
```

### Deploy a GitHub Pages

```bash
npm run deploy
```
