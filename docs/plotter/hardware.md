# Hardware

<img src="/img/plotter/proyecto.jpg" alt="El plotter montado" width="520" />

Componentes principales del plotter:

| Componente | Detalle |
|---|---|
| Placa controladora | Arduino UNO |
| Shield | CNC Shield V3 |
| Drivers | 3× A4988 |
| Motores | 3× motores paso a paso (formato NEMA 17) |
| Alimentación | Fuente 12V |
| Levantamiento del lápiz | Pendiente |

## Estructura

La estructura está conformada por **perfiles** y por los **carritos** que desplazan los motores a lo largo de los ejes.

:::note
El diseño del hardware todavía no se comparte: está recibiendo modificaciones y va a cambiar.
:::
